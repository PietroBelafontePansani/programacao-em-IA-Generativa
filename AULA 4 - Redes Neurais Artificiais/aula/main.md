# Atividade 5 – Avaliação crítica

```
Framework,Complexidade,Nível de Detalhamento,Melhor uso para:
RTF,Baixa,Médio,"Tarefas rápidas e diretas (e-mails, resumos)."
CRAFT,Média,Alto,Contextos de negócios e ações específicas.
COSTAR,Alta,Máximo,"Planejamentos, estratégias e conteúdos complexos."
``` 
```
Resumo Crítico: O prompt simples é para extração e execução. O prompt estruturado é para estratégia e personalização.
```
```
Veredito Crítico: O COSTAR é uma ferramenta de especificação. Use-o quando você não quer que a IA apenas "responda", mas que ela pense sob as mesmas restrições e objetivos que um consultor humano pensaria.
```
