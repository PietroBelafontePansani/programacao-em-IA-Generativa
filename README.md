# 🚀 Curso de Programação em IA Generativa

Bem-vindo ao repositório do curso de **Programação em Inteligência Artificial Generativa**.
Aqui você encontrará materiais, exemplos práticos, exercícios e projetos desenvolvidos ao longo das aulas.

---

# 📚 Objetivo do Curso

Este curso foi criado para ensinar os fundamentos e aplicações modernas de:

* Inteligência Artificial
* Machine Learning
* Redes Neurais
* Processamento de Linguagem Natural (PLN)
* Visão Computacional
* Modelos Generativos
* IA Personalizada
* Vibe Coding com IA

Ao final do curso, você será capaz de desenvolver aplicações inteligentes utilizando ferramentas e modelos de IA modernos.
